# Boombox Project
The Boombox Project is a terminal-based, illustrative boombox that I created. The idea behind is to introduce myself not only as someone with an interest in programming, but also as someone who enjoys sharing their musical taste.
Music player made for learning purposes.

DISCLAIMER: ALL songs included in this project are present solely because this code contains MY personal song list from MY Boombox. I am not claiming ownership, nor do I intend to infringe upon the copyrights of any of these songs. Once again, this project was created for the purpose of improving my programming skills, not for profit.

Since this project uses 'Just Playback', make sure you're on Python 3.9 or newer. If you have it, double click on "start.bat" to download requirements.

Controls:

- Enter: Play songs. If a song is already playing, it pauses.
- "<" or ">": Switches the currently displayed song. If a song is playing, immediately starts the next song.
- "+", "[", "-", "]": Increase volume by 10%, 1%, and vice versa for "-" and "]".
- "y" to enable autoplay if False by default and "n" for turning off.

This is currently a Work in Progress, being developed on "test" branch. Once I add everything I belive it's important for the Boombox Project complete release, it will be merged into the 'main' branch for the official release.

Site used to download all the mp3's: https://en.loader.to/4/
Just add your .mp3 files to the 'songs' folder and update the 'songs.json' file for custom display names.
