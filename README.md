# Boombox Project
The Boombox Project is a terminal-based, illustrative boombox that I created. The idea behind is to introduce myself not only as someone with an interest in programming, but also as someone who enjoys sharing their musical taste.
Music player made for learning purposes.
Still in creating phase, this is the "test" branch after all. It will be modulized and passed into the "main" branch when the time comes.
Currently, play songs (Enter), switch the displayed song with "<" + Enter and vice versa. And can pause (if the music is playing) by simply pressing Enter, also can increase or decrease volume by pressing "+" for 10% increase and "++" for 1% increase, the vice versa for "-", "--".

THIS VERSION'S AUTOPLAY: Must be pressed Enter right after a music ends (and to be enabled ofc). Next version will be added dynamic version.

Site used to download all the mp3's: https://en.loader.to/4/
